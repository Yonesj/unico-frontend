## 🎯 درباره پروژه

این پروژه رابط کاربری پلتفرم **Unico** است؛ سامانه‌ای که از دل چالش‌های واقعی دانشجویی متولد شد. هدف ما ساختن یک تجربه‌ی کاربری ساده، مدرن و روان برای حل دغدغه‌هایی مثل انتخاب واحد، پیدا کردن نظرات اساتید و مدیریت امور دانشگاهی است.

> برای آشنایی کامل با اهداف و ویژگی‌های پروژه، می‌توانید به [README ریپازیتوری بک‌اند](https://github.com/Yonesj/unico-backend) مراجعه کنید.

## 🛠️ پشته فناوری (Technology Stack)

این پروژه با استفاده از ابزارها و کتابخانه‌های مدرن زیر توسعه داده شده است:

| بخش                  | تکنولوژی                                                                                              |
| -------------------- | ----------------------------------------------------------------------------------------------------- |
| **فریم‌ورک و زبان**   | [React](https://reactjs.org/) (v18) و JavaScript                      |
| **ابزار بیلد**        | [Create React App](https://create-react-app.dev/) (`react-scripts`)                                   |
| **رابط کاربری (UI)**   | [Ant Design](https://ant.design/) (کتابخانه اصلی کامپوننت‌ها)                                       |
| **استایل‌دهی**        | [Tailwind CSS](https://tailwindcss.com/)                                                              |
| **مسیریابی (Routing)** | [React Router](https://reactrouter.com/) (v7)                                                         |
| **ارتباط با API**     | [Axios](https://axios-http.com/)                                                                      |

## 🚀 نصب و راه‌اندازی

برای اجرای پروژه به صورت محلی، مراحل زیر را دنبال کنید.

۱.  **کلون کردن ریپازیتوری:**
```bash
git clone https://github.com/Yonesj/unico-frontend.git
cd unico-frontend
```

۲.  **نصب وابستگی‌ها:**
```bash
npm install
```

۳.  **اجرای سرور توسعه:**
```bash
npm start
```

حالا می‌توانید اپلیکیشن را در مرورگر خود روی آدرس `http://localhost:3000` مشاهده کنید.
